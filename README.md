**Structure it**

- **[KOMPL](https://github.com/tuirk/Kompl)** · [kompl.wiki](https://kompl.wiki) · [video](https://youtu.be/OjLRpnpeFYY) · [article](https://medium.com/@tuirkey/bestie-sent-me-a-gist-and-three-weeks-later-we-have-kompl-186e4a3a1533)\

  Structures contested evidence: each claim quoted, linked by how it argues, and weighed.
