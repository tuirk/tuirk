## Selected knowledge projects

- **[Kompl](https://github.com/tuirk/Kompl)** · [1-min film](https://youtu.be/6zVYz6aHU1k)\
  An open source LLM-wiki that compiles bookmarks, docs, videos and repos into a wiki that reorganizes itself. Each new source merges into existing pages, so understanding builds up instead of piling up as notes. 80+ stars, MCP server.

- **RAG self-help agent for a retail SaaS** · NDA · Azure, Azure OpenAI\
  Lets users of a complex retail-optimization platform configure it, troubleshoot and understand its decision logic without going through support. A documentation layer I designed feeds hybrid retrieval for role-aware, cited answers and SQL help.

- **[SLR-Engine](https://github.com/tuirk/SLR-Engine)** · [film](https://youtu.be/iM_dbpH0aI0)\
  A coding agent runs a full systematic literature review, from research question to a screened, reproducible, auditable evidence set. The researcher makes the methodological calls at set checkpoints.

- **[pre-KOMPL](https://github.com/tuirk/pre-KOMPL)** · [film](https://youtu.be/-OAlPFSGt0s)\
  A library-grade catalog for everything you've bookmarked on YouTube, GitHub, X and the web, searchable in plain language by your agent.

- **EpiKompl** · [film](https://youtu.be/wd5pieKYoQs)\
  Kompl rebuilt as an argument graph for contested evidence: it pulls out each claim with its source and maps how the claims argue. Built for the FLF EpiStack competition.
