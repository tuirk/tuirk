# Tuana Irkey (Tui)

**Knowledge management for small teams: structure first, then the systems, tools, automation and agents that work from it.**

I work on how knowledge moves through a team: how people find it, when they can trust it, and what they do with it once they have it. I've done that since 2017, mostly in IT service operations, and I taught and [researched](https://scholar.google.com/citations?user=eL8tx2kAAAAJ) knowledge management at graduate level. Now I bring that practice to client work through my company, PivotGround, and build only what a team will actually use.

**How I help:** Documentation & Knowledge Flow · Product & Service Design · Continuous Improvement ([tuirkey.com](https://tuirkey.com/#services))

## Selected knowledge projects

- **[Kompl](https://github.com/tuirk/Kompl)** · [1-min film](https://youtu.be/6zVYz6aHU1k): an open source LLM-wiki that compiles your sources into linked pages, keeps them up to date and lets any agent read it over MCP.
- **Self-help agent for a SaaS platform** (client work, private): I documented a complex platform setting by setting, then built the RAG agent that answers from those docs with citations.
- **[pre-KOMPL](https://github.com/tuirk/pre-KOMPL)** · [film](https://youtu.be/-OAlPFSGt0s): turns your bookmarks into a catalog built the way libraries build them, searched by your agent.
- **[SLR-Engine](https://github.com/tuirk/SLR-Engine)** · [film](https://youtu.be/iM_dbpH0aI0): turns a systematic literature review into a process a coding agent runs, with researcher checkpoints and an audit log.
- **EpiKompl** · [film](https://youtu.be/wd5pieKYoQs): a knowledge graph for contested evidence that quotes each claim, links how claims argue and weighs each one.
